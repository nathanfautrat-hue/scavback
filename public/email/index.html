SCAVBACK mail kit

Ta signature et ton mail de remerciement, prêts à copier-coller dans Gmail. Remplis les champs à gauche, l'aperçu se met à jour, puis clique sur « Copier ».

01Signature

  1. Dans Gmail sur ordinateur : roue dentée → Voir tous les paramètres.
  2. Onglet Général, rubrique Signature → Créer.
  3. Colle avec Ctrl + V, puis tout en bas Enregistrer les modifications.
  4. Dans « Valeurs par défaut », choisis la signature pour les nouveaux e-mails et les réponses.

02Mail « Merci pour ton achat »

  1. Gmail → Nouveau message, colle l'objet puis le mail (Ctrl + V).
  2. Supprime ta signature automatique en bas : elle est déjà dans le mail.
  3. Vérifie le prénom et le montant, puis Envoyer.
